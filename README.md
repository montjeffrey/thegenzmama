# The Gen Z Mama

The website of [The Gen Z Mama](https://thegenzmama.com): childcare and
overnight newborn care in Wharton, New Jersey.

Next.js 16, React 19 and Tailwind CSS 4, with content in Sanity and hosting
on Netlify.

- **Editable without a developer:** services, reviews and blog posts live in
  Sanity, and the editing studio is built into the site.
- **A contact form that checks before it sends:** submissions are validated
  on the server and delivered by email through Resend; the API key never
  reaches the browser.
- **Pages:** home, about, services, in-home care, reviews, blog and contact,
  animated with Framer Motion.

Built by [Jeffrey Montoya](https://github.com/montjeffrey) as part of a 2025
complimentary launch special. This repository is a clean snapshot of the
production site.
